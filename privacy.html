Hermes — Privacy Policy

Last updated: October 2026

What this app does

Hermes is a private, personal automation assistant used only by its owner. When the owner authorizes it, it accesses the owner's own Gmail account through the Google Gmail API with the gmail.readonly scope: it can see and read mail, and nothing else. It cannot send, modify, or delete mail.

Data we collect and how we use it

The app requests only the data needed to read the owner's mail at the owner's request. Authorization tokens and retrieved mail data are stored locally on the owner's own computer. No data is sold, shared with third parties, used for advertising, or used to train any model. Data retained is limited to what the owner explicitly asks the assistant to fetch and keep.

Removing access and deleting data

The owner can revoke the app's access at any time from the Google Account permissions page (myaccount.google.com/permissions). Revoking access stops all data access immediately. Locally stored data can be deleted by deleting the app's stored tokens and files on the owner's computer.

Google API Services User Data Policy

Use of the Gmail API complies with the Google API Services User Data Policy, including the Limited Use requirements.
